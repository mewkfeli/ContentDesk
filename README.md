# ContentDesk 2.8.0

Локальное рабочее пространство контент-менеджера и SEO-инструменты.

## AI-команда

AI-слой работает через Ollama. Модели назначаются отдельно ролям: Координатору, Контент-редактору, SEO-специалисту и Фактчекеру.

Рекомендуемый старт:

```powershell
ollama pull qwen3:4b-instruct
ollama pull qwen3:8b
ollama pull deepseek-r1
```

## Project Memory 2.0

Память хранится в SQLite ContentDesk, а не внутри конкретной модели.

В памяти есть три слоя:

- **Знания** — факты, правила, решения, предпочтения и наблюдения.
- **Текущее состояние** — последние результаты аудитов, которые обновляются при повторном запуске.
- **История** — события проекта: аудиты, задачи и другие действия.

При первом запуске 2.8.0 ContentDesk автоматически добавляет подготовленный стартовый контекст для известных проектов, если они уже есть в базе. Импорт идемпотентный: повторный запуск не создаёт дубли.

После нового аудита сайта, перелинковки, Description или индексации актуальная сводка автоматически попадает в `Текущее состояние`, а запуск — в `Историю`. Создание и обновление сохранённых задач также фиксируется в истории.

AI-специалисты получают не всю базу целиком, а ограниченный срез: постоянные знания + актуальное состояние + последние события, релевантные выбранному проекту.

## Обновление

Распакуйте update-архив поверх текущего ContentDesk с заменой файлов. `contentdesk.db` в update-архив не входит и не перезаписывается. После запуска схема БД обновится до v9.
